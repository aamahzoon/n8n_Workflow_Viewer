# n8n Workflow Viewer

یک ابزار Streamlit برای بارگذاری و **مشاهده‌ی تعاملی** فایل‌های JSON خروجی n8n.
این برنامه هیچ workflow ای را اجرا نمی‌کند — فقط برای بررسی و مرور ساختار workflow است.

## نصب

```bash
pip install -r requirements.txt
```

## اجرا

```bash
streamlit run app.py
```

مرورگر به‌صورت خودکار باز می‌شود (معمولاً روی `http://localhost:8501`).

## امکانات

- بارگذاری فایل JSON خروجی n8n (از منوی n8n: **Download** یا **Export**)
- نمایش گراف تعاملی نودها و اتصالات (کلیک، درگ، زوم)
- رنگ‌بندی خودکار نودها بر اساس نوع (تریگر، شرط، HTTP، دیتابیس، پیام‌رسانی و ...)
- پنل جزئیات هر نود با کلیک: نوع، پارامترها، یادداشت، موقعیت
- ماسک خودکار مقادیر حساس (پسورد، توکن، کلید API) در نمایش پارامترها و credentials
- جستجو و فیلتر نودها بر اساس نام یا دسته
- جدول کامل لیست نودها و نمایش خروجی خام JSON

## نکته‌ی امنیتی

مقادیر حساس (فیلدهایی مثل `password`, `token`, `apiKey`, `secret`, `credential`) به‌صورت خودکار
در نمایش ماسک می‌شوند، اما فایل JSON اصلی شما (که آپلود می‌کنید) دست‌نخورده باقی می‌ماند و در
هیچ سروری ذخیره نمی‌شود — همه‌چیز فقط در حافظه‌ی محلی مرورگر/سشن اجرا می‌شود.


# تغییرات اصلی نسبت به نسخه‌ی قبلی:

**شباهت بصری به n8n:**
- نودهای معمولی: جعبه‌ی مربعی گردگوشه با آیکون در وسط (دقیقاً مثل canvas خود n8n)
- نودهای تریگر: فرم پرچمی/نوک‌تیز مشخصه که n8n برای تریگرها استفاده می‌کنه (با `clip-path`) — بدون نقطه‌ی ورودی، چون تریگر خودش شروع جریانه
- نقطه‌های اتصال (پورت) کوچیک روی لبه‌ی چپ/راست هر نود
- خطوط اتصال با منحنی بزیه (Bezier) دقیقاً مثل n8n، با فلش در انتها
- پس‌زمینه‌ی نقطه‌چین تیره، شبیه grid واقعی n8n
- پشتیبانی از Sticky Note (یادداشت‌های زرد شفاف که در workflow های واقعی زیاد دیده می‌شن)
- رنگ‌بندی بر اساس دسته (تریگر سبز، شرط نارنجی، HTTP آبی، دیتابیس طلایی و...)

**تعامل:**
- پن با درگ ماوس، زوم با اسکرول یا دکمه‌ها، دکمه‌ی «تناسب با صفحه»
- جستجوی زنده (بدون رفرش صفحه) که نودهای نامرتبط رو کم‌رنگ می‌کنه
- فیلتر بر اساس دسته با چک‌باکس
- کلیک روی نود → پنل جزئیات کنار صفحه (نوع، پارامترها، یادداشت، credentials — با ماسک خودکار)

در ضمن یک باگ امنیتی کوچیک هم پیدا و رفع کردم: الگوی متداول هدر HTTP در n8n (`{name: "Authorization", value: "Bearer ..."}`) قبلاً ماسک نمی‌شد، حالا این حالت هم پوشش داده می‌شه.

با `sample_workflow.json` تستش کن تا شکل نهایی رو ببینی.
